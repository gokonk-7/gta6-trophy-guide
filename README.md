Neon Leonida — GTA VI Trophy Guide & Tracker. An offline web app that is the best guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a checklist saved in the browser, export and import, filters by kind, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, the missable trophies flagged, and a guide to each trophy in our own words citing sources. Own look, no Rockstar logo or official artwork.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in your browser. Works with the network off.
