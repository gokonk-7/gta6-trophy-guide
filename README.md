# Neon Leonida — GTA VI Trophy Guide & Tracker

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, built for the make.fun competition `gta6-trophy-guide-01`.

## Features

- **Checklist tracker** — tick trophies off as you earn them; progress is saved in your browser's localStorage, so it survives reloads.
- **Export / import** — back up your progress to a file and restore it on any device.
- **Filter + search** — filter by grade (Bronze, Silver, Gold, Platinum), kind, and status, and search by trophy name or keyword.
- **Spoiler mode** — hides story and hidden trophies so nothing is spoiled before you play.
- **3-phase roadmap** — a structured route to the Platinum: story first, then side content, then clean-up.
- **Missables page** — every missable trophy listed with how to avoid losing it.
- **Next-up planner** — suggests what to chase next based on what you have already unlocked.
- **Fully offline** — no network calls, no trackers, no external assets; everything runs locally.

## How to run

```bash
node serve.ts
```

Then open http://localhost:8080/ in your browser.
